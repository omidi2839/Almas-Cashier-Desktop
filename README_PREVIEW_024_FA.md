# نسخه 0.2.4 ویندوز — تکمیل نمای آفلاین آزمایشی
مبنای منو و فرم: مرکز فروش 0.3.85 و حسابداری فروش 0.2.10. داشبورد WPF و اتصال قبلی حفظ شده‌اند. نمای مستقل فاکتورها: پنج کارت، فیلتر تاریخ، کارشناس، نوع فروش، وضعیت، جستجو، صفحه‌بندی، جزئیات، کالاهای چندردیفی، مجموع و تعدیل نمونه، پرداخت آزمایشی، استرداد جزئی برای ویرایش، حذف فقط بدون پرداخت/تحویل. خروجی CSV قابل باز کردن در Excel و چاپ نمونه از چاپگر ویندوز (PDF با چاپگر PDF). ثبت سفارش جداگانه بدون رزرو. همه داده‌ها ساختگی و صرفاً حافظه همان اجرا، بدون صف ارسال یا اثر مالی؛ قیمت و تخفیف رسمی تنها پس از اتصال. عملیات گروهی و بخش‌های مالی و لجستیکی تکمیل نشده‌اند. منوی واقعی پس از HTTPS فقط از سرور و مطابق مجوز می‌آید.
