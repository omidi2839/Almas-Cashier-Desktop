# 0.2.2 — پیش‌نمایش WPF
بازطراحی مستقل WPF با منوی سمت راست، چهار کارت، جدول تمام عرض با مرتب‌سازی و جستجو، دکمه‌های گرد، حذف وظایف و فعالیت‌ها. فونت از فونت‌های موجود ویندوز، فارسی و راست به چپ. نسخه آزمایشی؛ اطلاعات واقعی وارد نشود. فقط آزمون سلامت HTTPS؛ عملیات مالی و همگام‌سازی فعال نیست. کد WinForms قبلی حفظ و از کامپایل کنار گذاشته شده است.
