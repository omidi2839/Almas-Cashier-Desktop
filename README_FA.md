# صندوق فروش الماس — نسخه اول ویندوز 0.1.0

## خروجی چیست؟

این **پروژه قابل ساخت** یک برنامه Windows Forms با Microsoft Edge WebView2 است. این فایل ZIP حاوی **EXE کامپایل‌شده نیست**، چون روی محیط ساخت فعلی .NET SDK ویندوز و امکان دانلود پیش‌نیازها وجود ندارد. برای ساخت Setup.exe از اسکریپت و GitHub Actions آماده استفاده کنید.

### امکانات نسخه اول

- ورود با حساب واقعی Perfex از داخل برنامه؛ رمز عبور در برنامه نوشته/ذخیره/ثبت نمی‌شود.
- منوی اختصاصی شامل فقط: فاکتورها، دریافتی از فروشندگان، مدیریت صندوق، خروج و ارسال کالا، مرجوعی کالا.
- WebView2 واقعی با امکان بازشدن مودال‌های وب موجود؛ نه بازسازی دوباره فرم‌ها.
- حذف اجزای منوی اصلی Perfex و قسمت آماری بالای فاکتور در نمای برنامه.
- مخفی‌کردن دو دکمه ورود گروهی و پرداخت گروهی بدون حذف قابلیت‌های سرور.
- کنترل آدرس سرور و محدودسازی ناوبری صفحه به پنج بخش و صفحه ورود.
- مجوز ورود صندوقدار فقط پس از تأیید سمت سرور و فقط برای staffidهای تعیین‌شده.
- گزینه خروج از حساب، تازه‌سازی صفحه و تنظیم آدرس سرور.
- اطلاعات وب و کوکی نشست فقط در پروفایل محلی WebView2 کاربر ویندوز نگهداری می‌شوند.

## قدم اول — نصب ماژول کنترل دسترسی روی سرور

۱. فایل `Almas_Cashier_Portal_0.1.0_Perfex_Module.zip` را که در کنار بسته پروژه ارائه شده، در بخش ماژول‌های Perfex نصب و فعال کنید.
۲. با حساب **مدیر سامانه** آدرس `/admin/almas_cashier_portal/settings` را باز کنید.
۳. شناسه کارکنان (مثلاً 38,39) را ثبت کنید. این‌ها فقط مثال‌اند؛ صندوقدار واقعی را انتخاب کنید.
۴. صندوقدار باید در خود Perfex مجوز موردنیاز فاکتورها، دریافتی فروشندگان، مدیریت صندوق، ارسال و مرجوعی را داشته باشد. ماژول کنترل دسترسی به‌صورت خودکار مجوز مالی ایجاد نمی‌کند.

**هشدار امنیتی:** مخفی‌کردن منو، محدودسازی مسیر در WebView و فهرست مجاز ورود جایگزین RBAC در Perfex نیستند؛ دسترسی‌های اضافی کاربران صندوق را در مدیریت نقش‌ها حذف کنید. همچنین HTTP امن نیست و توصیه اکید به فعال‌سازی HTTPS داریم.

## قدم دوم — ساخت نسخه EXE/Setup روی ویندوز 64 بیتی

۱. فایل ZIP پروژه را کامل روی دیسک استخراج کنید؛ **داخل فایل ZIP اجرا نکنید**.
۲. .NET 8 SDK را از `https://dotnet.microsoft.com/download/dotnet/8.0` نصب کنید.
۳. برای ایجاد Setup.exe استاندارد (آیکن دسکتاپ، Programs & Features و Uninstall) نرم‌افزار رایگان Inno Setup 6 را نصب کنید: `https://jrsoftware.org/isinfo.php`.
۴. داخل پوشه استخراج‌شده، روی `tools\\build-windows.cmd` دوبار کلیک کنید.
۵. اگر ساخت موفق باشد، فایل‌های زیر ایجاد می‌شوند:
   - `artifacts\\publish\\AlmasCashierDesktop.exe` (اجرای مستقیم)
   - `artifacts\\installer\\AlmasCashierDesktop_v0.1.0_Setup_Windows_x64.exe` (نصب استاندارد)

اگر .NET SDK یا Inno Setup نصب نباشد، پیغام روشن دریافت می‌کنید؛ نیازی به اجرای فایل `.ps1` از پوشه موقت ZIP نیست.

**راه دوم برای ساخت EXE:** پروژه را داخل یک مخزن GitHub قرار دهید و workflow موجود در `.github/workflows/windows-release.yml` را از بخش Actions به‌صورت دستی اجرا کنید. نتیجه به‌صورت artifact قابل دریافت خواهد بود.

## قدم سوم — اولین ورود صندوقدار

۱. برنامه را باز کنید؛ صفحه لاگین واقعی Perfex در داخل پنجره برنامه نمایش داده می‌شود.
۲. در صورت نیاز با «تنظیم اتصال»، نشانی سرور را تغییر دهید؛ پیش‌فرض `https://sejadalmas.iq` است.
۳. با حساب مجاز صندوقدار وارد شوید. پس از بررسی سمت سرور، صفحه فاکتورها باز خواهد شد.
۴. هنگام ورود، هیچ رمز عبوری وارد فایل تنظیمات اپلیکیشن نمی‌شود.

اگر سامانه هنوز HTTPS ندارد، تغییر آدرس به HTTP فقط با تأیید صریح هشدار امنیتی ممکن است و خطر افشای رمز وجود دارد.

## محدودیت‌های نسخه اول

- این نسخه **آفلاین نیست** و برای کارکرد، به اتصال سرور نیاز دارد.
- ایجاد، ویرایش، پرداخت و مرجوعی به همان منطق فعلی سرور متکی‌اند؛ خطاهای تاریخ یا محاسبات مالی موجود در سرور خودبه‌خود برطرف نمی‌شوند.
- سیستم نسخه اول مجوزهای اختصاصی را از Perfex می‌گیرد و هنوز «حالت کاملاً مجزای سروری صندوق» برای هر پنج کنترلر ایجاد نمی‌کند.
- چیدمان پنج صفحه داخل WebView با CSS اختصاصی مخفی‌سازی تنظیم شده است و لازم است روی نسخه واقعی Perfex و اندازه صفحه صندوقدار آزمون شود.
- اجرا و کامپایل واقعی روی ویندوز در این محیط قابل انجام نبود و نباید این سورس را نسخه تست‌شده عملیاتی تلقی کرد.

## محتویات پروژه

`AlmasCashierDesktop/` سورس C# + WebView2

`backend/` سورس ماژول Perfex محافظ ورود

`installer/` دستور ساخت Setup.exe استاندارد

`tools/` اجرای ساخت یک‌کلیکی با Windows PowerShell

`.github/workflows/` ساخت خودکار روی Windows GitHub Actions

`assets/` آیکن نرم‌افزار
