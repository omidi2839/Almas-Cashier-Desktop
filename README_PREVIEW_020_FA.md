# الماس ویندوز — 0.2.0 پیش‌نمایش رابط بومی
بر اساس ماکاپ مصوب: رنگ نارنجی، کرم، چیدمان RTL، منوی راست، کارت‌های آماری، جدول، وظایف، فعالیت‌ها و نقش آزمایشی صندوقدار/حسابدار. داده‌ها نمونه‌اند و تغییرات آزمایشی فقط در حافظه همین اجرا قرار دارند. این نسخه ورود واقعی، چاپ معتبر، پایگاه داده آفلاین عملیاتی، صدور قطعی فاکتور، پرداخت یا همگام‌سازی مالی ندارد. فقط نشانی HTTPS درگاه در تنظیمات محلی ذخیره می‌شود. آزمون اتصال فقط GET مسیر /almas-cashier-api/health است و هیچ مجوز یا توکنی ارسال نمی‌کند. نرم‌افزار قدیمی WebView در سورس حفظ شده اما نقطه ورود جدید آن را اجرا نمی‌کند. زبان فارسی است؛ عربی در مرحله بعد. نسخه آزمایشی را با اطلاعات واقعی استفاده نکنید.
